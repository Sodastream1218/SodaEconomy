# Maintainers

## Current maintainer

- [@Sodastream1218](https://github.com/Sodastream1218) — project owner and lead maintainer

## Responsibilities

Maintainers are responsible for:

- protecting transaction and storage integrity;
- reviewing public API and schema changes;
- triaging issues and security reports;
- maintaining compatibility and migration documentation;
- approving releases and release notes;
- ensuring required verification passes before merge;
- managing repository labels, milestones, discussions, and project planning.

## Decision model

SodaEconomy currently uses a lead-maintainer model. Community feedback and technical proposals are
welcome, but final decisions on scope, architecture, compatibility claims, and releases belong to the
project maintainer.

New maintainers may be added after sustained, trustworthy contributions and familiarity with the
transaction, storage, identity, and integration architecture.
